# engine/

Password analyzer used by the "Défendre Camille" mode and the debrief.

Copied unchanged from [password-tool](https://github.com/intolyympe/password-tool)
(`js/`, commit `5ea89ee`): `strength.js`, `personal.js`, `wordlists.js`,
`eff-wordlist.js`, `generator.js`. Fix bugs there first, then copy again.

Credits:
- Pattern-matching approach inspired by [zxcvbn](https://github.com/dropbox/zxcvbn) (MIT).
- [EFF large wordlist](https://www.eff.org/dice) (CC BY 3.0 US).
